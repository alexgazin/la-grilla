# Промпт: волна 2026 · часть 2 — ещё 100 пунктов (этапы 10–19)

Продолжение `docs/IDEAS_2026_PROMPT_RU.md`. Действуют **те же** роль, контекст, жёсткие правила (§2), процесс этапа (§3) и критерий «Готово, когда». Порядок исполнения: этапы 1–9 первой части, затем 10–19 этой. Каждый пункт описан по шаблону:

- **Зачем** — какую боль снимает;
- **UX** — что видит человек, идентификаторы для тестов;
- **Домен / звук** — типы, где правило живёт (`MusicDomain`, ядро, `Session`), лимиты;
- **Тесты** — доменные (Linux) и UI (точечный прогон в CI);
- **Приёмка** — проверяемое условие;
- 🔑 — что нужно от владельца.

Пересечений с исполненными 84 идеями старого роадмапа и с 40 пунктами первой части нет; где пункт развивает уже сделанное, это сказано явно.

## Этап 10 · «Плавная работа» (юзабилити ежедневных действий)

**U21 · Мини‑транспорт в каждой шторке.** Зачем: чтобы послушать, приходится закрывать шторку. UX: тонкая панель внизу любой шторки‑редактора (`sheet.transport.play`, `.loop`, позиция такт:доля); уважает аудиции (во время аудиции показывает «Аудиция» и Стоп). Домен: нет; `Session.togglePlay`. Тесты: UI — в Piano Roll и редакторе аккорда Play/Stop не закрывает шторку. Приёмка: в 8 основных шторках есть транспорт.

**U22 · Фокус на секции.** Зачем: работать над припевом, не слушая всю песню. UX: долгое нажатие на чип секции → «Фокус» (`section.focus`): луп ровно по секции, сетка и Piano Roll ограничены ею, индикатор «Фокус: Припев» с крестиком. Домен: `Session.focusSection` (луп‑диапазон, не правка проекта). Тесты: UI — фокус включает луп на границах секции, выход возвращает прежний луп.

**U23 · Undo внутри шторки.** Зачем: сейчас Undo только в заголовке студии. UX: кнопки Undo/Redo в тулбаре всех редакторов‑шторок (где их нет), одинаковые иконки и идентификаторы `<экран>.undo/.redo`. Тесты: UI в редакторе аккорда и микшере.

**U24 · Подсказки жестов при первом использовании.** UX: однократные «coach marks» у реального элемента (пинч на сетке, долгое нажатие на Undo, свайп по пэду для velocity), кнопка «Понятно»; список «Подсказки» в настройках для повторного показа. Домен: `CoachMarks` (какие показаны, `@AppStorage`). Тесты: UI — подсказка показывается один раз; в `--uitesting` выключены по умолчанию, отдельный флаг `--coach-marks` для теста.

**U25 · Контекстная справка «?».** UX: в тулбаре каждого экрана «?» → карточка 3–5 пунктов + ссылка на подробный раздел (офлайн, из `Resources/Help/*.md` EN/RU). Тесты: доменный — у каждого экрана есть статья в обоих языках (аудит); UI — открыть справку Джема.

**U26 · Понятное сохранение.** UX: значок сохранения (есть) по нажатию → карточка «Сохранено 12:04 на этом iPhone», «Вернуться к последнему сохранению» (с подтверждением, через версию U7), «Сохранить копию». Тесты: UI — карточка и возврат.

**U27 · Перетаскивание между местами.** UX: drag & drop клипа на другую дорожку/секцию (есть внутри дорожки — расширить), пэда на пэд (обмен звуков, `pad.drag`), аудио/MIDI‑файла из «Файлов» (Split View/drag на iPad) в проект. Домен: `PadEditing.swap`, импорт существующий. Тесты: домен swap; UI — перетащить пэд 1 на пэд 5.

**U28 · Внешняя клавиатура на iPhone.** UX: пробел — Играть/Стоп, ⌘Z/⇧⌘Z, R — запись, L — луп, ←/→ — такт, 1–3 — вкладки, ⌘K — поиск действий (U4); подсказка по удержанию ⌘ (`UIKeyCommand` discoverability). Тесты: UI с `typeKey` в симуляторе.

**U29 · Удержание = предпрослушивание везде.** UX: долгое нажатие на аккорд, ноту, звук, пресет, вариант — звучит, пока держишь; отпустил — тишина. Одинаково на всех экранах. Домен: `Session.previewHold(_:)`/`endHold` поверх `audio.preview`. Тесты: UI — удержание аккорда в сетке не меняет проект.

**U30 · Единый порядок в меню «⋯».** UX: для дорожки, клипа, секции, пэда, версии одинаковая структура: Послушать · Переименовать · Дублировать · Цвет · … · Удалить (всегда последним, красным). Аудит‑скрипт проверяет порядок по идентификаторам. Тесты: аудит + UI выборочно.

## Этап 11 · «Выбор и буфер»

**U31 · Множественный выбор в аранжировке.** UX: режим «Выбрать» (`grid.select`), касания добавляют клипы/секции, панель действий: Дублировать, Удалить (в корзину U8), Сдвинуть, Цвет, Заглушить. Домен: `ClipEditing.batch(_:ids:)` — одна правка. Тесты: домен — групповое удаление/сдвиг атомарно; UI — выбрать 3 клипа → удалить → Undo.

**U32 · Буфер La Grilla между проектами.** UX: «Копировать аккорды / ритм / мелодию» в меню секции и клипа, «Вставить» в другом проекте — с предпросмотром (AuditionBar) и подстройкой тональности. Домен: `MusicClipboard {kind, events, sourceKey, bpm}` в `UIPasteboard` с собственным UTI (`com.alexgazin.lagrilla.music`), `Arrangement.paste(_:into:at:transpose:)`. Тесты: домен — вставка с транспонированием, лимиты; UI — копия между двумя проектами.

**U48 · Переименование двойным касанием.** UX: двойное касание имени дорожки, секции, версии, проекта → поле ввода на месте; Enter — сохранить (одна правка), Esc/касание вне — отмена. Тесты: UI для секции и дорожки.

**U65 · Повторить последнее действие.** UX: ⌘Y и пункт в поиске действий «Повторить: <действие>» (например, «Транспонировать +2», «Дублировать секцию»). Домен: `RepeatableCommand` — последние параметризованные действия каталога U4. Тесты: домен — повтор применяет ту же операцию к текущему выделению.

**U53 · Избранное везде.** UX: звезда у звуков, пресетов, прогрессий, паттернов, шаблонов; фильтр «Избранное» в каждой библиотеке. Домен: `Favorites` (локально, по стабильным идентификаторам). Тесты: домен — сохранение/восстановление; UI — отметить звук → фильтр.

**U54 · Недавнее.** UX: в библиотеках раздел «Недавние» (последние 12 звуков/пресетов/прогрессий). Тесты: домен — порядок и лимит.

**U52 · Поиск звуков с прослушиванием в одно касание.** UX: поле поиска в выборе звука и библиотеке сэмплов, результаты слушаются касанием по иконке, не закрывая список; теги (бочка, тёплый, лоу‑фай). Домен: `SoundIndex.search(query:)` по именам/тегам RU/EN. Тесты: домен — 30 запросов.

## Этап 12 · «Проекты и продолжение»

**U33 · Превью проекта в списке.** UX: в карточке проекта — мини‑волна/сетка секций; долгое нажатие → 10 секунд припева. Домен: `ProjectThumbnail` (рендер формы по `Compiler.notes`, кеш в пакете). Тесты: домен — миниатюра детерминирована; UI — долгое нажатие играет и останавливается.

**U34 · Сортировка, фильтры, закреплённые.** UX: сортировка (изменён/создан/имя/темп), фильтр по тональности/темпу/тегам, «Закрепить» сверху. Домен: расширение `ProjectSummary` (теги уже есть I74), `pinned` в настройках устройства. Тесты: домен — сортировки и фильтры.

**U35 · Осмысленное имя по умолчанию.** UX: новый проект называется «Ля минор · 92 · вторник» (или по шаблону); можно отключить. Домен: `ProjectNaming.suggest(key:bpm:date:locale:)`. Тесты: домен RU/EN.

**U36 · Продолжить с того места.** UX: открытие проекта возвращает экран, секцию, позицию транспорта, выбранную дорожку и зум. Домен: `WorkspaceState` в пакете (`workspace.json`, вне Undo и вне музыкальных данных). Тесты: домен — кодирование; UI — перезапуск возвращает Джем и секцию 2.

**U51 · «Начать с …» в пустом проекте.** UX: карточки быстрого старта (жанр + темп + тональность + палитра) в пустом проекте и на экране «Новый»; превью по удержанию. Домен: существующие шаблоны (I88) + `QuickStart` пресеты. Тесты: UI — карточка создаёт проект с нужным темпом.

**U70 · «Что нового» после обновления.** UX: один раз после обновления — шторка с 3–5 пунктами сборки и кнопкой «Попробовать» к каждому. Домен: `WhatsNew` по `CFBundleVersion`, тексты в `Resources/WhatsNew/<build>.json` EN/RU. Тесты: показ один раз; аудит наличия текста для текущей сборки.

**U61 · «Поделиться как в прошлый раз».** UX: кнопка в шторке экспорта и в меню проекта — тот же формат, диапазон и настройки, что в прошлый раз. Тесты: UI — повторный экспорт без выбора формата.

**U62 · Место на устройстве.** UX: в настройках «Хранилище»: размер проектов, версий, корзин, кешей звуков; «Очистить кеш» и «Удалить старые версии…». Предупреждение при < 500 МБ свободно перед записью. Тесты: домен — подсчёт размеров на временной папке.

## Этап 13 · «Видно и слышно, что происходит»

**U37 · Индикатор «что звучит».** UX: в заголовках дорожек и в микшере — метр уровня; в аранжировке подсвечивается играющий клип; пэды мигают при воспроизведении. Звук: уровни дорожек из ядра (атомарные пики, чтение 30 Гц вне аудиопотока — как плейхед). Тесты: C++ — пики дорожек; UI — индикатор меняется при игре.

**U41 · Тактильные метки сетки.** UX: лёгкая вибрация на границах тактов при перетаскивании клипа/ноты и прокрутке сетки (отключаемо). Тесты: домен — позиции меток; UI нет (haptics не наблюдаемы) — проверка флага.

**U47 · Цвета дорожек.** UX: выбор цвета дорожки из палитры Luz (8 цветов, AA‑контраст), применяется в сетке, микшере, Piano Roll. Домен: `Track.color: Int?`. Тесты: валидация диапазона; UI — смена цвета.

**U55 · «До/после» для эффекта с выравниванием громкости.** UX: у EQ, драйва, лимитера, палитры — переключатель «Обход» с автоматическим выравниванием громкости (LUFS), чтобы сравнение было честным. Звук: `LoudnessMeter` на коротком окне, компенсация gain в аудиции. Тесты: домен — компенсация в пределах 0,5 LU.

**U56 · Визуальный метроном.** UX: мигание долей в транспорте/на весь экран (крупно для сцены), сильная доля другим цветом; работает и без звука клика. Тесты: домен — фаза доли из тика; UI — индикатор существует при игре.

**U57 · Визуализация звука для слабослышащих.** UX: вспышки на ударах по пэдам, полоса громкости, подписи «бочка/малый» на ударах; включается в «Доступности». Тесты: UI — режим показывает метки ударов.

**U58 · Озвучка позиции для VoiceOver.** UX: VoiceOver объявляет «Такт 3» при смене такта во время игры (не чаще раза в такт), «Запись началась», «Дубль 2 записан». Тесты: доменный — частота объявлений; UI — `accessibilityValue` транспорта.

**U59 · Контраст и толщина сетки.** UX: настройка «Линии сетки: тонкие / обычные / толстые», режим высокой контрастности для сетки и ролла. Тесты: аудит контраста для режимов.

## Этап 14 · «Удобно руками»

**U39 · Плотность интерфейса.** UX: компактный/обычный/крупный режимы (размер ячеек, отступы), не путать с Dynamic Type. Домен: `StudioMetrics` от настройки. Тесты: UI — снимки трёх режимов без перекрытий.

**U40 · Режим для левши.** UX: зеркальная раскладка — транспорт и панели справа налево, пэды 1–16 справа налево (настройка). Тесты: UI — порядок фреймов пэдов зеркальный.

**U42 · Защита от случайных касаний в записи.** UX: во время записи всё, кроме пэдов/клавиш и Стоп, заблокировано (затемнено) — включается опцией «Замок в записи». Тесты: UI — касание вкладки во время записи ничего не делает.

**U43 · Отсчёт до записи голосом.** UX: «3‑2‑1» голосом/кликом на выбор, крупные цифры; настраиваемая длина (1 или 2 такта). Звук: короткие сэмплы счёта в ресурсах (свои). Тесты: домен — тайминг отсчёта по темпу.

**U44 · Режим «Практика».** UX: зациклить фрагмент, замедлить до 50–100% без смены тона (time‑stretch уже есть), счётчик повторов, отметка «получилось». Тесты: домен — диапазон и скорость; UI — режим включается из транспорта.

**U45 · Подсказка «следующий шаг».** UX: после ключевых действий одна ненавязчивая подсказка («Бит готов — добавить бас?», «Аккорды есть — напеть мелодию?») с одним действием; «Больше не показывать». Домен: `NextStepAdvisor.suggest(project:lastAction:)`. Тесты: домен — правила; UI — подсказка после записи бита.

**U50 · Не беспокоить во время записи.** UX: предложение включить Фокус‑фильтр «Запись» (App Intents `SetFocusFilterIntent`): в фокусе приложение открывается сразу в последнем проекте и не показывает подсказки. Тесты: сборка интента; домен — состояние фильтра.

**U60 · Простой режим.** UX: при первом запуске «Простой / Полный»: простой скрывает продвинутые панели (микшер‑инсерты, MIDI, автоматизацию), открывая их по мере использования («Показать больше» в каждом экране). Домен: `FeatureLevel`. Тесты: UI — в простом режиме нет MIDI‑устройств в настройках, «Показать больше» их открывает.

**U63 · Эко‑режим при низком заряде.** UX: при Low Power Mode — меньше анимаций, живой фон статичен, частота метров 15 Гц, подсказка «Эко‑режим: звук не меняется». Тесты: домен — выбор частоты; UI — флаг `--low-power` выключает фон.

**U64 · Поворот без потерь.** UX: смена ориентации сохраняет выделение, позицию прокрутки, открытую шторку и зум. Тесты: UI — выделенная нота остаётся выделенной после поворота.

**U66 · Запись не теряется при уходе.** UX: если во время записи свернуть приложение, прийти звонку или открыть другую шторку — дубль сохраняется как есть, показывается «Дубль сохранён, запись остановлена». Домен: `DrumRecordingDraft.commit` при прерывании. Тесты: UI — уход в фон во время записи → дубль в «Слоях».

**U67 · Превью шаблонов по удержанию.** UX: шаблоны, стили, палитры звучат 4 такта по удержанию карточки. Тесты: UI — удержание включает аудицию, отпускание — выключает.

**U46 · Понятные ошибки с действием.** UX: каждая ошибка — что случилось + что сделать + кнопка («Нет доступа к микрофону» → «Открыть настройки»). Аудит: все `MusicError`/`SampleError` имеют текст действия. Тесты: аудит‑скрипт.

**U69 · Подсказки в полях ввода.** UX: в ассистенте, поиске действий, имени проекта — примеры и автодополнение («темп…», «в ля минор», «добавь припев»), история запросов. Домен: `QuerySuggestions` из каталога U4 и истории промптов (I41). Тесты: домен — топ‑5 подсказок по префиксу.

## Этап 16 · «Сочинение» (музыкальные возможности)

**I21 · Прогрессии по настроению.** UX: «Настроение» (грусть, свет, напряжение, ностальгия, драйв) → 4 прогрессии с объяснением («IV–V–iii–vi: светлая тоска»), AuditionBar, применить к секции. Домен: `MoodProgressions` (правила функций и движения баса, детерминированный seed). Тесты: домен — все варианты в ладу, объяснения непустые.

**I22 · Модуляция между секциями.** UX: у секции «Тональность: как песня / +1 / +2 / своя»; партии транспонируются в секции, ударные не трогаются. Домен: `Section.transpose: Int?`, учёт в `Compiler.notes` для гармонических и мелодических дорожек. Тесты: домен — ноты в секции сдвинуты, экспорт MIDI с новой тональностью маркером.

**I23 · Автоматический финал.** UX: «Добавить концовку» → последний такт: замедление (после I2) или стоп‑аккорд с ферматой, удар тарелки; варианты A/B. Домен: `EndingGenerator`. Тесты: домен — финал в пределах песни, `hasComposedEnding`.

**I24 · Триоли и нечётные деления в шагах.** UX: у дорожки шагов деление 1/8, 1/16, 1/8T, 1/16T, 1/32; сетка шагов перестраивается. Домен: шаг‑тик = barTicks/деление, валидация. Тесты: домен — позиции триолей; UI — переключение деления.

**I25 · Вероятность и условия шагов.** UX: у шага ударных или ноты: вероятность (25–100%), условие (каждый 2‑й/4‑й проход, только в первый).
