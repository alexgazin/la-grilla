# Политика конфиденциальности La Grilla

Действует с 15 ноября 2026 года. Относится к приложению для iPhone, выпускаемому alexgazin из этого репозитория.

La Grilla не собирает, не передаёт и не продаёт персональные данные. В приложении нет аккаунтов, рекламы, аналитики, идентификаторов отслеживания и сервера разработчика. Сторонние SDK не получают ваши проекты и записи.

Проекты, ноты, назначения MIDI и записи голоса хранятся в локальном контейнере приложения. Резервное копирование iOS может включать эти файлы в соответствии с настройками Apple. Удаление приложения удаляет его локальный контейнер; экспортированные файлы и резервные копии подчиняются правилам выбранного хранилища. Удалите проект в разделе «Проекты», чтобы удалить его локальные файлы. Переносимые пакеты содержат исходные записи голоса, сохранённые в проекте: учитывайте это при передаче другим людям.

Микрофон используется только после вашего запуска записи мелодии или диктовки команды. Анализ мелодии выполняется на устройстве. Диктовка требует локального распознавания речи Apple и недоступна, если локальная модель выбранного языка не поддерживается. La Grilla не переключается на серверное распознавание. Команды можно вводить текстом без разрешения на микрофон и речь. Разрешениями можно управлять в настройках iOS.

Разрешение Bluetooth нужно для открываемого вами окна подключения MIDI-устройств. Подключённые MIDI-устройства передают музыкальные события и получают события только после выбора выхода. Bluetooth не используется для отслеживания местоположения. Звук инструментов и эффекты обрабатываются на iPhone.

Системное меню «Поделиться» и выбор файлов передают или импортируют файлы по вашему действию. Получатель или выбранный сервис управляет полученной копией. Ссылки на поддержку и репозиторий открываются в браузере; для сайта GitHub действует его политика конфиденциальности. Не публикуйте личные записи и проекты в открытых обращениях поддержки.

Настройка темы хранится в UserDefaults. Время работы системы используется только для согласования временных меток аудио и MIDI и измерения интервалов. Эти данные не передаются с устройства и не используются для идентификации пользователя.

По вопросам конфиденциальности и удаления данных [создайте обращение](https://github.com/alexgazin/la-grilla/issues). Перед добавлением функций, меняющих обработку данных, политика будет обновлена.
