# La Grilla — детали готового iOS-приложения

Сверка выполнена по `main` **`648e6e8915402df1d326de84874f2ea2178823c4`**, кандидат **1.0.0 (14), schema 8**. Это 20 пунктов финальной полировки: первый запуск, понятные настройки, сохранность работы, доступность, доказательная демонстрация и выпуск.

**ЕСТЬ** означает, что возможность найдена в исходниках и относится к принятой программной базе [C7](release/C7_ACCEPTANCE.md). Это не приёмка ещё изменяемого пакета полировки. **В РАБОТЕ** — реализация или новые доказательства готовятся; статус не равен PASS. **ОТКРЫТО** — требуются реальные устройства, модель, пользовательская запись или distribution-процедура. После изменений приложения результаты и кадры привязываются к новому source SHA.

## Как завершить пакет полировки

Сначала принять пункты 02–05 и 07 на новой native-сборке, затем повторить затронутые сценарии 06, 08–16. Для каждого результата записать source SHA, версию/build, CI run, фактически выполненные методы, оригинальные PNG и оставшиеся дефекты. Документ обновляется по этим receipts; наличие кода или подготовленного теста не переводит статус в PASS. Физические пункты 18–20 заполняются отдельно.

Для пункта 17 после получения и проверки записи:

1. Проверить видео и звук, отдельно указать Simulator/физическое устройство, virtual fixtures и любые монтажные стыки. Сохранить первоначальный файл захвата и проверяемое происхождение звука.
2. Извлечь постер из принятого видео на кадре с Play/видимым состоянием приложения; GIF тоже брать из этой записи. Не дорисовывать UI, ноты, таймер или касания. Все производные изображения связать с исходным MP4 и его SHA-256.
3. На главной README первой поставить подписанную запись «Работающее приложение — запись iOS Simulator» либо фактического iPhone и заметную ссылку на MP4 со звуком. Старое motion-промо оставить ниже с подписью «Презентация возможностей». Статичная галерея продолжает открывать полные оригиналы.
4. Добавить только готовые poster/GIF/MP4 и provenance; проверить ссылки и читаемость README на узкой и широкой странице. Проверки установленного iPhone, реальной модели или живого вокала от этого автоматически не закрываются.
