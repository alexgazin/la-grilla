## Перенос и DAW

1. Создайте проект с личным набором и вручную подрезанным сэмплом, экспортируйте `.grillapack`.
2. Откройте его на втором iPhone после перезапуска. Сравните воспроизведение, MIDI, WAV и стемы.
3. Импортируйте стемы и MIDI в DAW участника (по возможности Ableton Live или GarageBand). Запишите версию DAW, точку старта, темп, число дорожек, хвосты эффектов и поведение маркеров. Уже известные особенности: в LMMS удары округляются по сетке до 9,72 мс; в Ardour стемы совпали с WAV (отчёт сборки 43). Задержка палитры Chillhop — мастер‑эффект, в стемы она не входит.

## Приоритет дефектов

Выпуск блокируют:
- потеря проекта;
- краш в основном пути;
- пропажа звука без восстановления;
- неправильное сохранение правки.

Для каждого блокирующего случая приложите воспроизведение, исправление (коммит) и повторную проверку на затронутом устройстве. Остальные дефекты ранжируются по ущербу для музыканта.
