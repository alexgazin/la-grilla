# Host-only measurements after catalogue metadata changes

Run `bash /tmp/grilla-architecture-profile-after/run.sh` against the preserved source snapshot. This command never edits or reads mutable application source. It verifies every snapshot file before building the external executable with Swift 6.1.2, `-c release`.

`source-snapshot.json` pins each byte of MusicDomain's Package.swift, Sources and Tests plus any other package files outside build/cache directories. It records the stable-copy timestamp, base commit, per-file SHA-256 and aggregate digest. The snapshot includes uncommitted metadata, rename, allocation handling and concurrent musical-domain additions. The base commit is provenance only and must not be described as the exact compiled AFTER source. `source-tracked-diff.patch` preserves the tracked portion; per-file hashes also cover new untracked source files. Repo state may continue to change without affecting this run.

P1/P3 archive bytes are copied from the immutable BEFORE fixture baseline at commit `29adf6c398173faf830de8f6249702628b8a3f76`. Current domain migrations decode them. They must still compile to exactly 768 / 16,384 notes. BEFORE artifacts remain unchanged in `/tmp/grilla-architecture-profile-before` and the original `/tmp/grilla-architecture-profile`.

The direct-operation protocol is unchanged: 15 timed samples after one warmup for validate, Compiler.notes, legacy History.apply mix change and History.apply drum-note velocity change. No performance claim is made for any other newer mix API. Libraries contain 10 or 50 independently identified valid projects; setup/save and first warmup are separate from five timed list() calls. Then measure one separate listSummaries() warmup and five timed metadata lists, plus one summary(selectedID) warmup and 15 timed single-document metadata queries. All metadata scalar fields must match stored canonical values; all returned entries must have no error, and counts must match. Assertions run outside measured durations. Retained-summary counts describe the returned API values, not process RSS; ProjectSummary has no Project/events/patterns field.

`receipt.json` preserves raw durations, min/median/nearest-rank p95/max, setup and warmup costs, library bytes and query counts. `provenance.json` adds actual toolchain, host metadata, harness hashes, fixture hashes and source snapshot identity.

This is a warm-filesystem Linux process benchmark. It does not measure SwiftUI, Session.sync, AVAudioEngine, rendering deadlines, iPhone CPU/memory/temperature, touch latency or physical dropouts. BEFORE/AFTER were sequential runs on a shared host; relative timings establish this measured workload, not statistical device guarantees. No metadata cache or persistence architecture was rewritten by the profiler.
