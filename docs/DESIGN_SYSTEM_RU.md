# La Grilla · дизайн‑язык «Luz»

*Свет на графите.* Один язык для всего приложения: экранов, кнопок и музыкальных инструментов. Документ — источник правил. Код дизайн‑системы лежит в `App/Theme.swift` и `App/DesignSystem.swift`.

Исследование рынка (ноябрь 2026) — в разделе «Откуда это» в конце.

## 1. Три слоя

| Слой | Что это | Материал |
| --- | --- | --- |
| **Контент** | сетка песни, Piano Roll, списки, формы | матовый графит, тонкий шов, без стекла |
| **Оболочка** | таб‑бар, транспорт, тулбары, плавающие панели | Liquid Glass на iOS 26; на iOS 18 — `.ultraThinMaterial`; при Reduce Transparency и Increase Contrast — сплошная заливка |
| **Инструменты** | пэды, клавиши, фейдеры, ручки, шаги секвенсора | непрозрачные, слегка приподнятые; при игре загораются цветом своей дорожки |

Правило Apple соблюдаем буквально: стекло — только слой управления, никогда «стекло на стекле», никогда стекло под инструментом.

## 2. Цвет

Семантические токены, у каждого четыре варианта: тёмный, светлый и оба с Increase Contrast.

| Токен | Тёмная | Светлая | Назначение |
| --- | --- | --- | --- |
| `ink` | `#0E0F12` | `#F5F4F0` | фон («тёплая бумага» днём) |
| `panel` | `#16181D` | `#FFFFFF` | карточки, поверхности |
| `raised` | `#1E2127` | `#ECEAE4` | приподнятые элементы, покой инструмента |
| `lifted` | `#272B33` | `#E2DFD7` | третья высота: нажатие, активный сегмент |
| `studioText` / `muted` / `outline` | как раньше | | текст, вторичный текст, швы |

Акценты закреплены за смыслом и нигде не перекрашиваются:

- **мята** — игра, главное действие, фокус;
- **янтарь** — гармония;
- **лаванда** — ударные;
- **бирюза** — бас;
- **коралл** — только запись и опасность.

У акцента три ступени: покой (35 %), активен (100 %), удар — свечение поверх покоя (аддитивно, затухает 120–250 мс, сила зависит от velocity).

Контраст: текст ≥ 4,5 : 1, элементы управления ≥ 3 : 1 (WCAG 2.2). В Increase Contrast — сплошные заливки и обводки 1,5 pt. Проверку выполняет `scripts/audit_presentation.py`.

## 3. Типографика

Только системные шрифты (SF) через `Font.system`. Встраивать их не нужно и нельзя.

| Роль | Шрифт | Где |
| --- | --- | --- |
| `display` | SF Pro, ширина `.expanded`, semibold | заголовки экранов и пустые состояния |
| `title` | SF Pro, semibold | заголовки разделов |
| `action` | SF Pro, semibold | кнопки |
| `label` / `detail` | SF Pro, caption | подписи, капсулы |
| `pad` | SF Rounded, semibold | названия пэдов, большие числа |
| `value` | SF Mono с моноширинными цифрами | BPM, позиция, ноты, дБ |

Минимальный кегль — 11 pt; аудит его проверяет. Dynamic Type поддерживается везде; в размерах доступности инструменты переключаются на списки.

## 4. Форма и ритм

- Отступы: 4 / 8 / 12 / 16 / 24 / 32.
- Радиусы, все с `.continuous`:
  - 6 — клавиша;
  - 10 — ячейка, шаг, пэд в компактном режиме;
  - 14 — пэд, карточка;
  - 18 — большая поверхность;
  - 22 — шторка, навигация;
  - капсула — кнопка действия.
- Область касания — не меньше 44 × 44.

## 5. Движение

Модель Apple «длительность + упругость». Пресеты описаны в `Luz.Motion`.

| Пресет | Длительность | Упругость | Где |
| --- | --- | --- | --- |
| `tap` | 0,18 с | 0 | нажатие |
| `release` | 0,32 с | 0,25 | отпускание |
| `snap` | 0,30 с | 0,15 | переключатели, детенты, сегменты |
| `morph` | 0,45 с | 0,12 | стекло, шторки, раскрытия |
| `gentle` | 0,6 с | 0 | фон, вступление |

- **Инструменты.** Касание мгновенное: в кадре касания, без анимации. Анимируется только затухание света после отпускания.
- **Перетаскивание.** Сохраняется скорость жеста (`interactiveSpring`).
- **Reduce Motion.** Вместо пружин — короткие наплывы; фоновое движение выключается.
- **Частота экрана.** 120 Гц включены для iPhone (`CADisableMinimumFrameDurationOnPhone`).

## 6. Хаптика

Описана в `Luz.Haptics`.

| Событие | Отклик |
| --- | --- |
| детент ручки и фейдера, 0 дБ, привязка к сетке, сегмент | `selection` |
| удар по пэду | лёгкий удар, сила = velocity; отключается в опциях Jam |
| старт и стоп транспорта, запись | `impact medium` / `soft` |
| экспорт готов | `success` |
| клиппинг | `warning` |
| команда ассистента не понята | `error` |

Во время записи хаптика разрешена через `setAllowHapticsAndSystemSoundsDuringRecording(true)`. Интенсивность соответствует движению; хаптика не повторяет каждое событие.

## 7. Компоненты

| Компонент | Правило |
| --- | --- |
| **Кнопка действия** | капсула высотой ≥ 48. Главная — мята с тёмным текстом; вторичная — `raised` с акцентным текстом. При нажатии проседает на 2 %. |
| **Тихая кнопка** | без фона в покое; при нажатии подложка `lifted`. |
| **Иконка** | SF Symbols, иерархическая заливка, анимации символов (`bounce` на действие, `replace` при смене состояния). |
| **Сегменты** | подложка `ink`, выбранный сегмент — мятная «шайба», переезжает пружиной `snap`. |
| **Поверхность** | `panel`, радиус 18, шов, верхний световой край (кроме Increase Contrast). |
| **Оболочка** | `StudioNavigationSurface`: стекло или материал. |
| **Пэд** | непрозрачный, радиус 14, приподнят. При ударе — цвет ударных, свечение изнутри, проседание 3 %; затухание света 0,22 с. Без размытия, шейдеров и `TimelineView` на поверхности пэдов. |
| **Клавиша** | «слоновая кость» и графит, радиус 6. Нажатая клавиша проседает и окрашивается цветом дорожки; лад подсвечивается. |
| **Фейдер** | толстая капсула, шкала дБ, детент с хаптикой на 0 дБ, двойной тап — сброс. |
| **Ручка** | детенты, двойной тап — сброс, значение моноширинным шрифтом. |
| **Метр** | LED‑сегменты с удержанием пика. Обновление из снимка 30–60 раз в секунду, никогда из аудиопотока. |
| **Пустое состояние** | символ, одна строка, одно действие; мягкий `MeshGradient` на 20 % (iOS 18+). |

## 8. Реальное время

На экранах Jam и Perform запрещены:

- Metal‑эффекты (`layerEffect`) и размытие;
- непрерывные `TimelineView`, кроме спектра в микшере;
- состояние SwiftUI, которое обновляется из аудиопотока.

Свет пэда рисуется заранее посчитанным градиентом.

## Откуда это

Отчёт исследования от 19.11.2026:

- **Apple.**
  - [HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials): стекло — только слой управления.
  - [HIG Haptics](https://developer.apple.com/design/human-interface-guidelines/playing-haptics).
  - [HIG Color](https://developer.apple.com/design/human-interface-guidelines/color): четыре варианта цвета.
  - API iOS 26: `glassEffect`, `GlassEffectContainer`, `SensoryFeedback.press/release`.
  - Пружины: [Animation](https://developer.apple.com/documentation/swiftui/animation).
- **Motionary** ([сайт](https://alanfeiyuchang.github.io/motionary-ios-animations/), [MIT](https://github.com/alanfeiyuchang/motionary-ios-animations)). 839 эффектов SwiftUI. Нам подходят:
  - `rotate-knob`, `dial-knob` — ручки;
  - `elastic-slider`, `volume-pill` — фейдеры;
  - `segmented-slider` — метры;
  - `depth-press`, `lit-toggle`, `ink-ripple` — пэды, Mute/Solo;
  - `hold-record` — запись;
  - `jog-wheel` — Perform;
  - `numeric-counter` — BPM и позиция;
  - `mesh-gradient` — пустые состояния.

  Приёмы переносим в свои компоненты (Swift 6), с упоминанием MIT; зависимость не берём.
- **Библиотеки.** AudioKit Keyboard/Controls, EmergeTools/Pow, twostraws/Inferno и Vortex служат референсами. Зависимостей нет: офлайн, без телеметрии, безопасно для App Store.
- **Рынок.**
  - Logic Pro 13 перешёл на Liquid Glass вокруг матовых инструментов.
  - Ableton Note сделал режим высокого контраста.
  - Лидеры — плотные тёмные цветокодированные «железные» инструменты со стеклом только в оболочке.
  - Тренды 2026: выборочная тактильная глубина вместо полного скевоморфизма, спокойное осмысленное движение.

**Компоненты в `Theme.swift`.** Токены, `IconButton(isOn:)`, `StudioQuietButtonStyle(radius:plate:)`, `StudioSegments` с шайбой, `StudioNavigationSurface(solid:)`.

**Сделано по ревью дизайнера.**

- **Система:**
  - одна система кнопок;
  - формы на панели;
  - Dynamic Type вместо фиксированных кеглей;
  - непрерывные углы;
  - радиусы из токенов;
  - позиция транспорта читается только маленькими представлениями, поэтому экраны не перерисовываются 30 раз в секунду;
  - сплошная консоль на Jam.
- **Инструменты:**
  - пэды светятся по velocity;
  - шаги секвенсора с подсветкой играющего;
  - клавиши: проседание, затухание, подписи только на C и тонике;
  - one‑finger аккорды;
  - секции Perform светятся своим цветом;
  - фейдеры: относительное перетаскивание, 0 дБ, LED‑метры;
  - панорама и синтезатор на ручках;
  - Mute и Solo различаются.
- **Смысл цвета:**
  - курсор Piano Roll мятный;
  - предупреждения нейтральные, янтарь остаётся за гармонией;
  - эквалайзер и цвета секций — в цвете своей дорожки и секции.
- **Оболочка:**
  - шайба вкладок;
  - Play меняет символ;
  - баннеры `LuzNotice`;
  - статус сохранения символом;
  - тост на материале оболочки.
- **Экраны:**
  - экспорт плитками с символами;
  - A/B палитр;
  - пустые состояния;
  - поиск проектов;
  - анимированные раскрытия;
  - хаптика в Piano Roll;
  - обратный отсчёт и пульс записи голоса.
