# La Grilla development

Native iPhone studio: iOS 18+, Swift 6, SwiftUI, AVAudioEngine and a C++17 render kernel. The original README and DESIGN_PROMPT remain the product requirements; current delivery status is in [ROADMAP](../ROADMAP.md) and [QA](QA.md). Signing and publishing are described in [release procedure](release/RELEASE.md).

On a Mac with Xcode 26.3 (or an App Store-supported newer toolchain) selected:

```sh
python3 scripts/generate_project.py
open LaGrilla.xcodeproj
swift test --package-path Packages/MusicDomain
bash scripts/test_audio.sh
python3 scripts/audit_presentation.py
python3 scripts/release/audit_release.py
xcodebuild -project LaGrilla.xcodeproj -scheme LaGrilla \
  -destination 'generic/platform=iOS Simulator' -derivedDataPath DerivedData \
  CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO build
bash scripts/release/archive_unsigned.sh
```

The committed project is generated by the repository's Python script; XcodeGen is optional through `project.yml`. Update both version sources together. Signing requires the owner's Apple team/certificate/profile; no credentials are checked in. An unsigned simulator app or device archive cannot be installed as a distribution IPA.

On Linux, `scripts/test_domain.sh` supports `GRILLA_SWIFT_BIN` for a locally installed Swift 6 toolchain. `scripts/test_audio.sh` supports `GRILLA_CXX_BIN` and uses no Apple frameworks. Swift frontend parsing can check UI syntax on Linux, but only native SDK compilation and simulator/device execution establish iOS behavior.

Up to 8 tracks, 8 sections and 64 bars; PPQ 960. Harmony/Drums are first, with optional root Bass and independent Melody tracks. All music uses the same compiler for live playback, MIDI and offline audio. New preset version 2 uses rate-independent one-shots and bounded retirement tails; migrations preserve preset version 1, including frozen performance sources.

The render callback performs no file/network access, locking, actor work or dynamic allocation. Control data crosses bounded queues or triple-owned snapshots. Gain/pan/filter/delay updates adopt atomically at a buffer boundary; musical snapshots adopt at defined musical boundaries. MIDI input preserves source/channel/timestamps and does not echo to output. MIDI output runs on a separate serial worker. Panic, disconnect and output destination changes release notes.

Projects live in `Documents/Projects/<UUID>.grilla` with atomic `manifest.json`, a prior valid backup and optional validated original voice assets. Autosave is debounced; completed takes/lifecycle changes checkpoint immediately. Source originals remain attached to portable exports. Import creates an independent project, validates limits/path/CRC/hash/schema and never extracts arbitrary paths. See [schema](SCHEMA.md).

The Assistant is local and supports an explicit RU/EN command grammar. Proposals are scoped to a project/revision and applied as one Undo transaction. Dictation uses only on-device Apple Speech; unavailable models fall back to typed input. Voice-to-MIDI is monophonic, preserves original audio and exposes uncertainty/correction. Synthetic fixtures do not establish human-voice accuracy.

Playback can continue in the background after the user starts it, with system Play/Pause/Stop. Idle background graphs stop and release MIDI/audio resources. Microphone ownership is exclusive; background/interruption stops capture. Returning from an interruption preserves musical position and does not automatically resume recording.

CI saves both SDK logs, real XCTest screenshots, result bundles, portable/export fixtures, a simulator app and an optimized unsigned device archive. Screenshots are not generated artwork. Host timing, sanitizer and simulator results do not substitute for the final 30-minute physical/audio/MIDI/DAW matrix. [Hardening evidence](HARDENING_QA.md) records what is measured and what remains open.

The default verification run captures the complete native design. A commit message containing `[ui-only]` retains all 19 Studio flows, domain/audio checks, both SDK builds and the Release archive while skipping duplicate bulk captures. Adding `[compact-capture]` to that mode also captures all six English/Russian 375-point views. Capture waits for settled raw pixels where possible and keeps the selected native PNG unchanged. Use a full capture after a visible interface change; record the actual source SHA and inspect individual originals before preparing Store copies. Distribution still requires all three verification jobs to pass for the exact `main` commit.

All instrument audio is synthesized by the app. The icon was generated through OpenArt; provenance is retained. No downloaded sample pack, telemetry SDK, account backend, client API key or repository-wide open-source license is included.
