# La Grilla identity

The active [Design 2026 direction](2026/README.md) uses a musical grid crossed by a bright vertical playhead. The [current app icon](2026/openart-icon.png) was generated through OpenArt for this application and is packaged as the unchanged opaque 1024 × 1024 RGB PNG. The matching header mark is drawn in SwiftUI.

The concept board cost 54 credits and the icon 32; the observed balance after this pass is 497. Provider settings, source images and hashes remain in [2026](2026/). Native product screenshots are captured from the running app.

Graphite and warm text support a lime primary action, amber harmony, periwinkle drums and aqua bass. Light/dark tokens pass the repository's AA contrast audit. Large text and VoiceOver have the equivalent note list, mixer and pad controls; landscape retains a side transport.

The original nine-pad mint/amber icon and its generation record are retained in [OpenArt](OpenArt/) as evidence for R8–R10. That earlier generation used 32 credits and left 583 at that point. These historical assets are separate from the current icon.
