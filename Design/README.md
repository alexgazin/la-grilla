# La Grilla identity

The opaque 1024 × 1024 app icon was generated through OpenArt for this application on 15 November 2026. The original PNG and provider identifiers are retained in [OpenArt](OpenArt/). The app asset differs only by RGB conversion for App Store compatibility. The generation used 32 credits; the observed remaining balance was 583.

The nine mint pads reference the musical grid. The amber accent follows Harmony; drums and bass retain their separate blue and violet interface colors. Product screenshots always come from the running native application, never from image generation.

Interface colors adapt to system light/dark appearance, with a user override in Project settings. Text and accent token combinations are checked for WCAG AA contrast by `scripts/audit_presentation.py`. Piano-roll geometry remains proportional to pitch/time; large Dynamic Type and VoiceOver open the equivalent note list. Large-type mixer and pad layouts provide native, scrollable controls. Landscape uses a persistent side transport beside the musical workspace.
