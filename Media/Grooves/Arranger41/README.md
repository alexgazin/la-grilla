# Три проекта из текста

Эти файлы получены тем же офлайн-генератором и тембрами, которые использует приложение. Для каждого исходного описания подготовлен отдельный проект. Переносимый пакет снова открывался перед экспортом MIDI и стереозвука. Для редактирования пакетов нужна La Grilla со схемой 14 (сборка 41 или новее). MP3 можно послушать отдельно.

| Трек | Что слушать | Файлы |
| --- | --- | --- |
| Тренировка, 128 BPM | С 0:15 бас играет реже, хэт остаётся на «и». На 0:45 возвращаются партии A. | [MP3](workout.mp3) · [Проект](workout.grillapack) · [MIDI](workout.mid) |
| Chillhop, 90 BPM | Первый такт играет флейта. На 0:02,67 входит бит, следом фортепиано. С 0:45,33 аккорды разложены в арпеджио. На 1:06,67 один раз звучит гонг. | [MP3](chillhop.mp3) · [Проект](chillhop.grillapack) · [MIDI](chillhop.mid) |
| Медитация, 64 BPM | Вступление выдерживает гармонию C, B♭, G, A♭. На 0:30 вступает бансури, с 1:00 слышны редкие клавиши. С 1:15 начинается четырёхтактовое затухание. | [MP3](ambient.mp3) · [Проект](ambient.grillapack) · [MIDI](ambient.mid) |

Акустическое пианино использует комплектную запись из заводской библиотеки. Флейта, бансури, пэд и гонг синтезированы локально. MIDI переносит нотное исполнение и маркеры секций в другую студию. Для переноса тембров используйте проект, для передачи точного микса — стереозвук.

Оригинальные тексты Андрея сохранены в планах внутри пакетов. «Помощник» позволяет снова открыть план и сделать отдельную версию с изменёнными длинами, гармонией или плотностью исполнения.
