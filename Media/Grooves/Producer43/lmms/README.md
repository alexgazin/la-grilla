# Chillhop в LMMS 1.2.2

Импортирован тот же файл chillhop.mid, что и в проверке Ardour. LMMS сохранил редактируемый проект. После повторного открытия LMMS отрендерил стерео WAV при 44,1 кГц с локальным банком TimGM6mb. Валидированы 6 партий, 542 ноты и все высоты нот. Автоматизация темпа в нулевой позиции выставила 89,999954 BPM, размер 4/4.

Сетка LMMS в этом проекте составляет 48 импульсов на четверть при исходных 960. Начало 261 ноты совпало точно. Максимальное расхождение в позиции составило 10,42 мс, в длительности 13,89 мс. Наибольший сдвиг ударных составил 9,72 мс. LMMS не обработал четыре секционных маркера. Партии импортировались со стандартным комплектом ударных и фортепианным пресетом на остальных треках. Для исходного тембра и точного микротайминга при переносе подходят стемы La Grilla.

Файл MMP создан через Save Project As в LMMS после штатного импорта. Для воспроизведения на другой машине можно переназначить локальный банк SoundFont.
