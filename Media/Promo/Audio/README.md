# Оригинальная музыка для промо

Саундтрек «Lines into music» создан для [проморолика La Grilla](../la-grilla-promo.mp4)
и отрендерен штатным `MusicDomain.OfflineRenderer.renderPerformance` через C++
`AudioDSP`. Это offline-рендер настоящего движка приложения, а не запись с iPhone.
В нём нет чужой музыки, внешних семплов, речи или записей Vocadito.

96 секунд, 120 BPM, 4/4, 48 тактов в до мажоре. Процедурные инструменты приложения
играют аккорды, бас, мелодический мотив, арпеджио и ударные. Аранжировка развивается
по главам ролика; на 60–68 секунде звучат настоящие filter/delay движка. Финал
разрешается в C6/9 и затихает внутри 96 секунд.

В этой папке:

- [Нативный проект `.grillapack`](la-grilla-promo.grillapack) — редактируемая
  партитура и точная автоматизация performance take. Можно импортировать в La Grilla.
- [Партитура MIDI](la-grilla-promo-score.mid) — ноты по дорожкам; без воспроизведения
  автоматизации gain/filter/delay и тембров приложения.
- [Происхождение и параметры](audio-provenance.json) — исходный коммит, форма,
  хеши сохранённых файлов и ссылка на хеш несжатого мастера.
- [Анализ PCM](pcm-analysis.json) — уровни всего мастера, глав и финального хвоста.

Несжатый WAV размером 27,65 MB не хранится в Git. Он воспроизводится с помощью
[Swift CLI и инструкции](../../../Tools/PromoSoundtrack/README.md); музыка уже
включена в проморолик. Мастер — stereo PCM 48 kHz / 24-bit, ровно 4 608 000 кадров.
Референсный SHA-256:

```text
65e213074e3b6dd0510b9561aa100ee31339b0c0e2f755ae8cf87b28798bcaa6
```

Проверено автоматически: −18,5 LUFS, −3,2 dBTP, sample peak −3,585 dBFS,
RMS −20,513 dBFS, ни одного отсчёта на пороге клиппинга движка. Пик последних
100 мс — −97,57 dBFS. Два полных рендера на референсной платформе побайтово
совпали. Для повторной проверки готового WAV из корня репозитория:

```sh
python3 Tools/PromoSoundtrack/validate_audio.py /tmp/la-grilla-promo-audio/la-grilla-promo-96s-48k24.wav
ffmpeg -i /tmp/la-grilla-promo-audio/la-grilla-promo-96s-48k24.wav -filter_complex ebur128=peak=true -f null -
```

PCM-валидатор требует Python 3 и NumPy. Эти проверки подтверждают формат,
длительность, уровни и воспроизводимость; они не означают прослушивание человеком
или проверку физических аудиомаршрутов iPhone.
