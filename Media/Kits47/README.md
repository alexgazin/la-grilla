# Четыре новых заводских набора (I51)

Тот же двухтактовый бит 92 BPM, что и для Pocket, Dusty и Coast в [Producer43](../Grooves/Producer43/README.md): одинаковые удары, velocity и микс. Все звуки синтезируются на устройстве генератором `FactoryDrumKit` и не занимают места в приложении. Исходный генератор прежних трёх наборов не менялся: их звук остался бит‑в‑бит прежним.

| Набор | Характер | Прослушать |
| --- | --- | --- |
| 808 Trap | Длинная бочка 808 с глиссандо, тугой малый, быстрые хэты | [trap808.mp3](trap808.mp3) |
| House | Плотная бочка с щелчком, большой хлопок, яркие открытые хэты | [house.mp3](house.mp3) |
| Brushes | Войлочная бочка, щётки по малому, тёплый райд | [brushes.mp3](brushes.mp3) |
| World | Рамочный барабан, конги, «тек» в духе дарбуки, колокольчики | [world.mp3](world.mp3) |

Порядок пэдов прежний (Kick, Snare, Closed hat … Perc), поэтому MIDI и записанные рисунки звучат с новым набором без перестановки. Наборы выбираются в «Звуки → Pad samples → More kits». Проверки: каждый пэд — независимый ограниченный one‑shot с тишиной на краях (`FactoryDrumKitTests`).
